# Java Game Engine

### Object-Oriented Programming & Multithreading

A collaborative Java-based game project demonstrating modular software architecture, object-oriented design, and concurrent task execution.

## Project Overview

The application is organized into components for game logic, character management, combat, enemy behavior, and graphical user interfaces.

## Technical Highlights

- **Object-Oriented Design:** Modular Java classes organized into packages with distinct responsibilities.
- **Multithreading:** Uses Java's ExecutorService and a fixed thread pool to execute enemy tasks concurrently.
- **Concurrency Management:** Uses concurrent collections and AtomicBoolean to coordinate execution state.
- **Factory Pattern:** Uses an EnemyFactory component to create enemy objects.
- **Game Architecture:** Separates game engine logic, combat mechanics, character management, and graphical interface components.
